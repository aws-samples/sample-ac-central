# Field Guide

Positioning guidance, objection handling, and demo scripts for account teams. This content is for internal SA/AM use — not customer-facing documentation.

---

## Who This Is For

- **Solutions Architects** preparing for customer meetings where AgentCore is on the agenda
- **Account Managers** who need quick objection responses without deep technical context
- **Technical Account Managers** helping customers choose between workload types

## When to Use

- **Before a first meeting**: Read the relevant workload page for objection responses and the 5-minute demo path
- **During discovery**: Use the objection tables to address concerns in real-time
- **After a meeting**: Reference the demo scripts to build a follow-up proof of concept

For deep technical content (architecture, configuration, tutorials), use the main documentation sections instead.
