## Common Objections & Responses

<div className="fancy-table">

| Objection                                          | Response                                                                                                                         |
|----------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------|
| "Why not just GitHub Copilot / Cursor?"            | IDE copilots assist a human in real-time. AgentCore coding agents run autonomously on tasks (PRs, migrations, test gen) at scale. |
| "What about code quality and hallucinations?"      | Sandboxed Code Interpreter validates output (compile, test, lint) before committing. The agent iterates until tests pass.         |
| "How is this different from CodeWhisperer?"        | CodeWhisperer does inline completions. AgentCore coding agents do multi-file, multi-step tasks with full repo context.            |
| "What about security of generated code?"           | MicroVM isolation, no network access by default, and security scanning gates before any PR is opened.                             |
| "Is it production-ready?"                          | Blue Origin is running coding agents on AgentCore for aerospace software development.                                             |

</div>

## Key Differentiators vs Alternatives

| Capability                  | IDE Copilots       | AgentCore Coding Agents                      |
|-----------------------------|--------------------|----------------------------------------------|
| Execution model             | Human-in-the-loop  | Autonomous (with review gates)               |
| Scope                       | Single file / block | Multi-file, cross-repo                       |
| Validation                  | Human reviews      | Automated (compile, test, lint in sandbox)   |
| Trigger                     | Keystroke          | Ticket, PR, schedule, CI event               |
| Session duration            | Seconds            | Minutes to hours                             |
| Sandbox isolation           | None               | MicroVM with Code Interpreter                |
| Scale                       | 1 developer        | Concurrent tasks across many repos           |
