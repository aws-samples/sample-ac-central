Positioning, objection handling, and demo scripts for account teams.

## Common Objections & Responses

<div className="fancy-table">

| Objection                                          | Response                                                                                                                  |
|----------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------|
| "Why not just Lambda + API Gateway?"               | No session persistence, no memory, no microVM isolation, no identity token exchange. You'd rebuild half of AgentCore.     |
| "What about latency / cold starts?"                | Responses stream progressively via SSE, so users see output as it's generated rather than waiting for the full answer.    |
| "How does this compare to Azure AI Agent Service?" | Multi-model (any provider via Strands), bring-your-own-framework, no vendor lock-in on the model layer.                   |
| "What about cost at scale?"                        | Serverless pricing means no idle cost. Context optimization reduces per-turn token spend via summarization and retrieval. |
| "Is it production-ready?"                          | Cox, Ryanair, BGL, Kavak, Thomson Reuters, and Swisscom are in production today.                                          |

</div>

## What to Demo (5-Minute Path)

For the account team walking into a first meeting without a specreq:

1. **Deploy (before meeting)**: Sample conversational agent architecture at the [AgentCore Samples repo](https://github.com/awslabs/agentcore-samples)
2. **`agentcore dev`**: Show a local agent booting in seconds with hot reload.
3. **Send a message**: Show token-by-token streaming response in the terminal TUI.
4. **Add a Gateway tool**: Wire a Lambda target and show the agent calling it mid-conversation.
5. **Show the trace**: Open CloudWatch, filter by conversation ID, walk through the agent's reasoning and tool calls.
6. **Point to production**: `agentcore deploy` is one command to go from this demo to a scaled, isolated, monitored deployment.

**Key outcome message:** "We can go from this to production without managing infrastructure, building auth plumbing, or wiring observability. It's already built in."
