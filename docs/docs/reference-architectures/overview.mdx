# AgentCore Reference Architectures

Production deployments and customer case studies built on Amazon Bedrock AgentCore. These reference architectures demonstrate real-world patterns across industries — from healthcare and energy to media and automotive.

---

## How to Use This Section

Each reference architecture includes:
- **Architecture pattern** — The agent design pattern used (event-driven, chat, platform, coding, swarm)
- **Architecture diagram** — Visual representation of the solution (where available)
- **Customer story** — Business context, challenge, and solution
- **AgentCore services** — Which AgentCore capabilities power the solution
- **Results** — Measurable business outcomes

## Patterns at a Glance

| Pattern | Description | Example Customers |
|---------|-------------|-------------------|
| **Event-driven** | Agents triggered by business events, processing asynchronously | Rede Mater Dei, Iberdrola, Amazon Catalog |
| **Chat Agent** | Conversational agents with stateful sessions | BGL, Kavak, Parrot Analytics |
| **Platform** | Enterprise platforms standardizing agent development | Thomson Reuters, AutoScout24, Swisscom |
| **Coding** | Agents that generate, validate, or transform code | Blue Origin |
| **Swarm** | Multi-agent collaboration on complex tasks | LobeHub |
| **Multi-pattern** | Multiple agent patterns deployed together | Cox Automotive |
