# Your First Agent (Console)

:::tip Who this is for
First-time builders who prefer a UI-led experience without local tooling. If you want a code-first dev loop with version control and hot-reload, see [Build from CLI](/docs/get-started/quickstart).
:::

Deploy an agent through the AWS console without installing local tooling or writing orchestration code — the console handles resource creation, IAM role setup, and initial configuration on your behalf.

---

## Canonical tutorial

AWS does not yet publish a dedicated console walkthrough. The console UI is self-guided — start here:

- [Amazon Bedrock AgentCore console](https://console.aws.amazon.com/bedrock-agentcore/home#) — the UI walks you through creating a harness with a model, system prompt, and tools

For the documented procedural path (CLI and boto3):

- [Get started with the harness (CLI / boto3)](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/harness-get-started.html)

Prefer the terminal? Create the same agent in three commands:

```bash
agentcore create --name myfirstagent --model-provider bedrock
agentcore dev
```

This scaffolds a harness project and opens the browser test page where you can chat with your agent immediately.

---

## What you'll have at the end

A deployed agent with a reachable endpoint you can invoke and test interactively. The harness manages the agent loop, model configuration, and system prompt — see [Harness operations](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/harness-operations.html) for what you can configure after creation.
