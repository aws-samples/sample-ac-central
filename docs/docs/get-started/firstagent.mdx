# Your First Agent (Console)

## Choose this path when

You are a first-time agent builder who prefers a UI-led experience. You want to deploy an agent through the AWS console without installing local tooling or writing orchestration code.

## What it produces

Deploys a first agent via the console. You will have a working agent with a reachable endpoint that you can test interactively before considering production readiness.

## Start with the canonical tutorial

Follow the official AWS guide to create and deploy your first agent entirely through the console:

- [Create and deploy an agent in the AgentCore console](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/create-deploy-agent.html)

No alternative — this path has one recommended starting point.

## What Central adds

- **Reader profile:** This path suits builders who prefer a UI-led workflow and do not need local CLI tooling or a code-first development loop.
- **What the console path produces:** A deployed agent with a reachable endpoint, provisioned through the AgentCore console. The console handles resource creation, IAM role setup, and initial configuration on your behalf.
- **Central next step:** After you have tested your agent in the console, move to [Preparing for production](/docs/operate/production-readiness) to apply security, observability, and operational controls before serving real user traffic.

## Prototype and readiness boundary

:::caution Prototype boundary
**Prototype boundary:** This path is a prototype until you have applied the controls in [Preparing for production](/docs/operate/production-readiness). Do not use a prototype endpoint to serve real user traffic.
:::
