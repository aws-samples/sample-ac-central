# Pre-built Skills in AgentCore

:::caution Coming Soon
Pre-built skills are currently in development. This page outlines the planned experience.
:::

Curated, current knowledge of AgentCore best practices for coding agents. Accurate context available within coding agents from the very first line of code.

---

## Why Pre-built Skills?

- **Best practices baked in** — Skills encode AgentCore patterns, SDK idioms, and deployment best practices so coding agents produce correct code from the start.
- **Always current** — Skills are updated as AgentCore evolves. No stale documentation or hallucinated APIs.
- **Works with your tools** — Built for Kiro, Claude Code, Codex, and Cursor. Drop a skill into your IDE and start building.

---

## How It Works

| Step | Action |
|------|--------|
| 1 | **Install a skill** — Add an AgentCore skill to your coding agent (IDE plugin or config file) |
| 2 | **Start coding** — Ask your coding agent to build an agent. The skill provides accurate patterns and API references |
| 3 | **Deploy** — The generated code follows AgentCore conventions and deploys cleanly via CLI or CDK |
