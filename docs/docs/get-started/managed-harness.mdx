# Managed Harness

Fully managed, config-based agent service with no orchestration code needed. Stateful sessions with micro-VM isolation and flexible tooling with an export-to-code option for more control.

---

## Why Managed Harness?

- **Zero orchestration code** — Define your agent declaratively via configuration. AgentCore handles routing, memory, and tool invocation.
- **Stateful sessions** — Micro-VM isolation with sessions persisting up to 8 hours. No infrastructure to manage.
- **Flexible tooling** — Connect tools via AgentCore Gateway (MCP). Add, remove, or swap tools without redeploying.
- **Export to code** — Start managed, graduate to full code control when you need custom logic. No lock-in.

---

## Get Started in 4 Steps

| Step | Action | Details |
|------|--------|---------|
| 1 | **Open the AgentCore Console** | Navigate to the Amazon Bedrock AgentCore console in your AWS account |
| 2 | **Create an Agent** | Use the guided wizard to define your agent — select a model, add a system prompt, and attach tools |
| 3 | **Configure Tools** | Connect to APIs via AgentCore Gateway or add built-in tools (Code Interpreter, Browser Tool) |
| 4 | **Test & Deploy** | Test in the console playground, then deploy to a production endpoint |

---

## Key Features

- **Identity integration** — Attach an OAuth provider to enable user-scoped tool access
- **Memory** — Enable session memory (short-term) and user memory (long-term) with a toggle
- **Guardrails** — Add content filters, topic boundaries, and PII redaction from the console
- **Observability** — Tracing enabled by default — view in CloudWatch or export via OTLP
