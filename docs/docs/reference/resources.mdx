# Further Reading

Curated authoritative sources for building and operating agents with Amazon Bedrock AgentCore.

## AgentCore Platform

- [AgentCore Developer Guide](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/) — Complete reference for Runtime, Memory, Gateway, Identity, Observability, Evaluations, Policy, and Harness
- [AgentCore CLI](https://github.com/aws/agentcore-cli) — CLI source, release notes, and the authoritative `agentcore.json` schema reference
- [AgentCore Samples](https://github.com/awslabs/agentcore-samples) — End-to-end reference implementations covering workflow, conversational, and multi-agent patterns
- [AgentCore Code Interpreter](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/code-interpreter-tool.html) — Managed, isolated code execution environment with Sandbox, Public, and VPC network modes
- [AgentCore Browser Tool](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/browser-tool.html) — Managed browser sandbox for agents that interact with web applications, with AWS managed and custom browser options
- [AgentCore CloudFormation Resources](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/AWS_BedrockAgentCore.html) — CloudFormation resource types for provisioning AgentCore infrastructure as code
- [AgentCore CDK Constructs](https://docs.aws.amazon.com/cdk/api/v2/docs/aws-cdk-lib.aws_bedrockagentcore-readme.html) — AWS CDK L2 construct library for AgentCore resources
- [AgentCore Terraform Provider](https://registry.terraform.io/providers/hashicorp/aws/latest/docs/resources/bedrockagentcore_agent) — Terraform provider resources for AgentCore agent management

## Existing-Agent Adoption

- [Runtime Lifecycle Settings](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/runtime-lifecycle-settings.html) — Per-session microVM lifecycle, idle timeouts, and maximum lifetimes
- [AgentCore Pricing](https://aws.amazon.com/bedrock/agentcore/pricing/) — Active CPU and memory consumption rates and associated Runtime costs
- [Configure AgentCore Observability](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/observability-configure.html) — Framework instrumentation, ADOT, trace destinations, and CloudWatch configuration
- [Configure Runtime for VPC](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/agentcore-vpc.html) — Private-resource connectivity, ENIs, security groups, endpoints, and routing
- [Runtime Security Best Practices](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/runtime-security-best-practices.html) — Session isolation, least-privilege roles, network controls, and credential guidance
- [Runtime Credential Management (MMDS)](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/security-credentials-management.html) — How code in Runtime microVMs obtains temporary execution-role credentials
- [Cost-Efficient Initialization and Scale-to-Zero](https://docs.aws.amazon.com/wellarchitected/latest/agentic-ai-lens/agentcost06-bp03.html) — Well-Architected guidance for lifecycle settings, session reuse, and initialization caching
