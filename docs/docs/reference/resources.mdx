# Further Reading

Curated authoritative sources for building and operating agents with Amazon Bedrock AgentCore.

## AgentCore Platform

- [AgentCore Developer Guide](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/) — Complete reference for Runtime, Memory, Gateway, Identity, Observability, Evaluations, Policy, and Harness
- [AgentCore CLI](https://github.com/aws/agentcore-cli) — CLI source, release notes, and the authoritative `agentcore.json` schema reference
- [AgentCore Samples](https://github.com/awslabs/agentcore-samples) — End-to-end reference implementations covering workflow, conversational, and multi-agent patterns
- [AgentCore CloudFormation Resources](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/AWS_BedrockAgentCore.html) — CloudFormation resource types for provisioning AgentCore infrastructure as code
- [AgentCore CDK Constructs](https://docs.aws.amazon.com/cdk/api/v2/docs/aws-cdk-lib.aws_bedrockagentcore-readme.html) — AWS CDK L2 construct library for AgentCore resources
- [AgentCore Terraform Provider](https://registry.terraform.io/providers/hashicorp/aws/latest/docs/resources/bedrockagentcore_agent) — Terraform provider resources for AgentCore agent management

## Architecture and Best Practices

- [Well-Architected Agentic AI Lens](https://docs.aws.amazon.com/wellarchitected/latest/agentic-ai-lens/agentic-ai-lens.html) — Security, reliability, and operational best practices for agentic AI workloads
- [Well-Architected Generative AI Lens](https://docs.aws.amazon.com/wellarchitected/latest/generative-ai-lens/generative-ai-lens.html) — Cost optimization, performance, and governance guidance for generative AI
- [Agentic AI Security Scoping Matrix](https://aws.amazon.com/ai/security/agentic-ai-scoping-matrix/) — Risk classification framework mapping agent autonomy levels to security controls
- [Securing Agentic AI (Prescriptive Guidance)](https://docs.aws.amazon.com/prescriptive-guidance/latest/securing-agentic-ai/introduction.html) — Threat modeling and security architecture for autonomous agent systems
- [Serverless Generative AI (Prescriptive Guidance)](https://docs.aws.amazon.com/prescriptive-guidance/latest/serverless-generative-ai/introduction.html) — Patterns for building generative AI applications on serverless infrastructure
- [Memory-Augmented Agents (Prescriptive Guidance)](https://docs.aws.amazon.com/prescriptive-guidance/latest/memory-augmented-agents/introduction.html) — Design patterns for agents with persistent and episodic memory
- [Circuit Breaker for AI Agents (Prescriptive Guidance)](https://docs.aws.amazon.com/prescriptive-guidance/latest/circuit-breaker-ai-agents/introduction.html) — Fault-tolerance patterns preventing cascading failures in agent systems
- [Cedar Policy Language](https://www.cedarpolicy.com/) — Authorization policy language used by AgentCore for tool and resource access control

## Strands Agents SDK

- [Strands Agents Documentation](https://strandsagents.com/latest/documentation/docs/) — Official SDK docs covering agents, tools, models, and orchestration

- [Deploying Agents](https://strandsagents.com/latest/documentation/docs/user-guide/deploy/deploy-agent/) — Packaging and deployment options for Strands-based agents
- [Multi-Agent Patterns](https://strandsagents.com/latest/documentation/docs/user-guide/concepts/multi-agent/multi-agent-patterns/) — Coordinator, pipeline, and swarm patterns for multi-agent orchestration
- [Deep Dive: Building Agents with Strands](https://aws.amazon.com/blogs/machine-learning/build-agentic-ai-applications-with-strands-agents/) — Technical blog on building production agents with the Strands SDK

## Security and Governance

- [OWASP Top 10 for LLM Applications](https://owasp.org/www-project-top-10-for-large-language-model-applications/) — Industry-standard vulnerability taxonomy for LLM-powered systems
- [NIST AI 600-1: AI Risk Management](https://csrc.nist.gov/pubs/ai/600/1/final) — Federal framework for identifying and mitigating risks in AI systems
- [Cedar Policy Language Reference](https://docs.cedarpolicy.com/) — Specification and examples for writing Cedar authorization policies
- [Context Window Overflow in Agents](https://aws.amazon.com/blogs/machine-learning/addressing-context-window-overflow-in-ai-agents/) — Techniques for managing token limits in long-running agent conversations
- [Prompt Injection Mitigation](https://aws.amazon.com/blogs/machine-learning/protecting-ai-agents-from-prompt-injection/) — Defense patterns for preventing adversarial prompt manipulation

## Reliability Patterns

- [Amazon EventBridge for Event-Driven Agents](https://docs.aws.amazon.com/eventbridge/latest/userguide/eb-what-is.html) — Serverless event bus for decoupling agent triggers from processing logic
- [Amazon SQS Dead-Letter Queues](https://docs.aws.amazon.com/AWSSimpleQueueService/latest/SQSDeveloperGuide/sqs-dead-letter-queues.html) — Capture and retry failed agent invocations without data loss
- [Step Functions Error Handling](https://docs.aws.amazon.com/step-functions/latest/dg/concepts-error-handling.html) — Retry, catch, and fallback patterns for multi-step agent workflows
- [Human Approval with Step Functions](https://docs.aws.amazon.com/step-functions/latest/dg/callback-task-sample-sqs.html) — Callback patterns for pausing workflows pending human review
- [Tenant Isolation with IAM](https://docs.aws.amazon.com/prescriptive-guidance/latest/saas-multitenant-api-access-authorization/isolation-methods.html) — Resource and policy isolation patterns for multi-tenant agent deployments
- [Saga Pattern for Distributed Transactions](https://docs.aws.amazon.com/prescriptive-guidance/latest/modernization-data-persistence/saga-pattern.html) — Compensating transactions for reliable multi-service agent operations
