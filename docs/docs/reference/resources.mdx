# Public resources

Use these public resources to continue building and operating agents with Amazon Bedrock AgentCore.

## AgentCore CLI

The [AgentCore CLI repository](https://github.com/aws/agentcore-cli) contains the maintained CLI documentation, source code, and release notes. Use it for the latest commands and version-specific behavior.

For an overview of Amazon Bedrock AgentCore services and capabilities, see the [Amazon Bedrock AgentCore Developer Guide](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/).

## Samples

Explore the [AgentCore Samples repository](https://github.com/awslabs/agentcore-samples) for public end-to-end examples and reference implementations.
