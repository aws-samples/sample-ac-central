## The AgentCore stack at a glance

<ThemedImage
  alt="AgentCore platform stack diagram showing six managed service layers: Runtime (sandboxed execution), Memory (session and long-term storage), Gateway (MCP tool federation), Identity (OAuth/OIDC brokering), Observability (OTLP traces and evaluations), and Tools (Code Interpreter and Browser Tool)"
  sources={{
    light: useBaseUrl('/img/agentcore-platform.svg'),
    dark: useBaseUrl('/img/agentcore-platform-dark.svg'),
  }}
/>

AgentCore managed services that together form the agent platform.

<div className="stack-grid">
  <div className="stack-item">
    <h4>Runtime</h4>
    <p>Sandboxed container execution with long-running task support.</p>
  </div>
  <div className="stack-item">
    <h4>Memory</h4>
    <p>Short-term and long-term memory scoped per session, user, or project.</p>
  </div>
  <div className="stack-item">
    <h4>Gateway</h4>
    <p>Tool federation via MCP with inbound JWT auth and Lambda targets.</p>
  </div>
  <div className="stack-item">
    <h4>Identity</h4>
    <p>OAuth/OIDC token brokering - the agent never sees client secrets.</p>
  </div>
  <div className="stack-item">
    <h4>Observability</h4>
    <p>OTLP traces, metrics, and logs to CloudWatch with online evaluation.</p>
  </div>
  <div className="stack-item">
    <h4>Tools</h4>
    <p>Code Interpreter and Browser Tool as managed sandboxes.</p>
  </div>
</div>
