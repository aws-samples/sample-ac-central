Six managed services that together form the agent platform.

  </div>
  <div className="stack-item">
    <h4>Memory</h4>

  <div className="stack-item">

  </div>
  <div className="stack-item">
    <h4>Tools</h4>
    <p>Code Interpreter and Browser Tool as managed sandboxes.</p>
