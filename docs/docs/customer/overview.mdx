# AgentCore Customer References and Architectures

Production deployments and customer case studies built on Amazon Bedrock AgentCore. These reference architectures demonstrate real-world patterns across industries - from healthcare and energy to media and automotive.

:::info Sourcing
Stories are based on publicly available, externally approved sources. Every claim traces to a linked public reference; stories without a verifiable public source are not published.
:::

---

## How to Use This Section

Each customer reference includes:
- **Architecture pattern** - The agent design pattern used (workflow, Conversational, platform, coding, swarm)
- **Architecture diagram** - Visual representation of the solution (where available), with a text description of entry point, main flow, and key boundaries
- **Customer story** - Business context, challenge, and solution
- **AgentCore services** - Which AgentCore capabilities power the solution
- **Results** - Measurable business outcomes
- **Transferable lessons** - What the customer chose and why, stated as their decisions rather than universal prescriptions
- **When this is relevant** - Signals that indicate this pattern fits your context
- **Source and verification** - The public source link and last-verified date for every claim

## Patterns at a Glance

<div className="fancy-table">

| Pattern            | Description                                              | Example Customers                        |
|--------------------|----------------------------------------------------------|------------------------------------------|
| **Workflow**       | Agents triggered by business events, processing async    | Rede Mater Dei, Iberdrola, Formula 1     |
| **Conversational** | Conversational agents with stateful sessions             | BGL                                      |
