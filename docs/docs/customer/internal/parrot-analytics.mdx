## Customer Story

**Customer:** Parrot Analytics - Global content analytics company

**Challenge:** Media executives needing real-time audience and content intelligence but lacking technical skills to query complex datasets. Business teams were dependent on data analysts for every question, creating bottlenecks and limiting exploration.

**Solution:** Conversational agents providing content intelligence insights, enabling media executives to query audience data through natural language. The agent translates business questions into analytical queries and presents results with context and recommendations. Session memory allows follow-up questions to refine analysis.

## Lessons Learned

**Session memory is essential for analytics:** Business users naturally ask follow-up questions ("show that by region", "what about last quarter?"). Without session memory, each question requires full context re-entry.

**Show the query, not just the answer:** Displaying the translated SQL or API call helps users learn the data model and builds trust that the agent understood their question correctly.

**Visualizations beat tables:** For non-technical users, a simple chart is more actionable than a table of numbers. Build visualization primitives into your tool layer.
