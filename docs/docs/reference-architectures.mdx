## Rede Mater Dei {#rede-mater-dei}

**AI Agents for Healthcare Revenue Cycle**

🏷️ Pattern: Event-driven

📖 [Blog Post →](https://aws.amazon.com/blogs/machine-learning/rede-mater-dei-de-saude-monitoring-ai-agents-in-the-revenue-cycle-with-amazon-bedrock-agentcore/)

![Rede Mater Dei Architecture](/img/image69.png)

**Architecture:** Event-driven multi-agent pipeline for healthcare revenue cycle management

<div className="arch-flow">
  <span className="arch-flow-step">Hospital EHR/Billing Systems</span>
  <span className="arch-flow-arrow">→</span>
  <span className="arch-flow-step">Event Triggers (claims, authorizations)</span>
  <span className="arch-flow-arrow">→</span>
  <span className="arch-flow-step">12 Specialized AI Agents</span>
  <span className="arch-flow-arrow">→</span>
  <span className="arch-flow-step">AgentCore Runtime</span>
  <span className="arch-flow-arrow">→</span>
  <span className="arch-flow-step">Observability & Evaluations</span>
</div>

**Customer:** Rede Mater Dei de Saúde — Major Brazilian hospital network (45+ years, 8+ locations)

**Challenge:** Claim denials jumped to ~16% sector-wide (~R$10B lost revenue), driven by manual, fragmented billing processes

**Solution:** 12 AI agents on Amazon Bedrock AgentCore automating contracts, authorization, and billing — with built-in observability and governance

</div>

## Amazon.com Catalog {#amazon-catalog}

**Self-Learning GenAI at Scale**

🏷️ Pattern: Event-driven

📖 [Blog Post →](https://aws.amazon.com/blogs/machine-learning/how-the-amazon-com-catalog-team-built-self-learning-generative-ai-at-scale-with-amazon-bedrock/)

![Amazon Catalog Architecture](/img/image72.png)

**Architecture:** Generator-Evaluator-Supervisor self-learning architecture with continuous knowledge accumulation

<div className="arch-flow">
  <span className="arch-flow-step">Product Submissions (millions/day)</span>
  <span className="arch-flow-arrow">→</span>
  <span className="arch-flow-step">Generator Workers (Nova Lite × N)</span>
  <span className="arch-flow-arrow">→</span>
  <span className="arch-flow-step">Consensus Check</span>
  <span className="arch-flow-arrow">→</span>
  <span className="arch-flow-step">Supervisor (Claude Sonnet)</span>
  <span className="arch-flow-arrow">→</span>
  <span className="arch-flow-step">Knowledge Base</span>
</div>

**Customer:** Amazon.com Catalog Team — Millions of daily product submissions

**Solution:** Generator-evaluator-supervisor architecture. Lightweight workers handle routine cases. Disagreements trigger a supervisor that resolves disputes and extracts reusable learnings.

  <span className="result-chip">Costs decrease over time</span>
