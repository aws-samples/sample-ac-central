# Platform Powered by Bedrock AgentCore

Every layer of the agent platform stack maps directly to managed services in Amazon Bedrock AgentCore and the broader AWS ecosystem. This eliminates undifferentiated heavy lifting and lets platform teams focus on governance, developer experience, and business value.

---

## Platform Layer Mapping

<div className="fancy-table">

| Platform Layer | AgentCore / AWS Service | What It Provides |
|---|---|---|
| **AI Gateway** | AgentCore Gateway | Unified entry point, MCP tool federation, JWT auth, rate limiting, routing |
| **Registry & Discovery** | AgentCore Registry + Bedrock Model Catalog | Agent catalog, versioning, capability discovery, model selection |
| **Agent Runtime** | AgentCore Runtime | Sandboxed containers, micro-VM isolation, long-running tasks, auto-scaling |
| **Memory & Context** | AgentCore Memory + OpenSearch + S3 Vectors + Knowledge Bases | Short/long-term memory, vector search, RAG, session context |
| **Observability** | AgentCore Observability | OTLP traces, metrics, logs, online evaluation, guardrail events |
| **AgentOps** | AgentCore Evaluations + CI/CD tools | Offline/online evals, quality gates, drift detection, A/B testing |

</div>

## Supported Protocols

AgentCore is protocol-native, supporting open standards for interoperability across frameworks and ecosystems.

<div className="arch-flow">
  <span className="arch-flow-step">MCP (Model Context Protocol)</span>
  <span className="arch-flow-arrow">•</span>
  <span className="arch-flow-step">A2A (Agent-to-Agent)</span>
  <span className="arch-flow-arrow">•</span>
  <span className="arch-flow-step">OTEL (OpenTelemetry)</span>
</div>

- **MCP** - Tool federation and discovery. Agents connect to MCP servers through the Gateway without managing individual tool integrations.
- **A2A** - Cross-framework agent collaboration. Agents built with different frameworks communicate via the open A2A protocol.
- **OTEL** - Standardized observability. Traces, metrics, and logs flow via OpenTelemetry to AgentCore Observability and CloudWatch.
