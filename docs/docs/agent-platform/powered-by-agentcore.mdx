# Platform Powered by Bedrock AgentCore

:::tip Who this is for
Builders exploring which AgentCore capabilities apply to their agent design — understanding which platform layer maps to which managed service before committing to an architecture.
:::

Every layer of the agent platform stack maps to managed services in Amazon Bedrock AgentCore and the broader AWS ecosystem. This eliminates undifferentiated heavy lifting and lets platform teams focus on governance, developer experience, and business value.

Labels used throughout this page:
- **AgentCore-native** - behavior provided directly by an AgentCore service
- **Preview** - available in public preview; subject to change ([AgentCore docs](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/))
- **Adjacent AWS** - a separate AWS service that integrates with AgentCore
- **Customer-built** - a pattern you assemble on top of AgentCore capabilities

## Supported Protocols

AgentCore is protocol-native, supporting open standards for interoperability across frameworks and ecosystems.

<div className="arch-flow">
  <span className="arch-flow-step">MCP (Model Context Protocol)</span>
  <span className="arch-flow-arrow">•</span>
  <span className="arch-flow-step">A2A (Agent-to-Agent)</span>
  <span className="arch-flow-arrow">•</span>
  <span className="arch-flow-step">AG-UI (Agent User Interface)</span>
  <span className="arch-flow-arrow">•</span>
  <span className="arch-flow-step">x402 / MPP (Payment Protocols)</span>
  <span className="arch-flow-arrow">•</span>
  <span className="arch-flow-step">OTEL (OpenTelemetry)</span>
</div>

- **MCP** - Tool federation and discovery. Agents connect to MCP servers through the Gateway without managing individual tool integrations.
- **A2A** - Cross-framework agent collaboration. Agents built with different frameworks communicate via the open A2A protocol.
- **AG-UI** - Agent User Interface protocol for rich, interactive agent-to-human interfaces with structured UI components and streaming responses.
- **x402 / MPP** - HTTP-native payment protocols enabling agents to pay for services and APIs autonomously. AgentCore Payments, which implements both protocols for agent-to-agent and agent-to-service transactions, is generally available. A curated set of vetted pay-per-use endpoints is discoverable through the x402 Bazaar MCP Server, accessible via Gateway.
- **OTEL** - Standardized observability. Traces, metrics, and logs flow via OpenTelemetry to AgentCore Observability and CloudWatch.
